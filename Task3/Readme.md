# Список проблем:
Взаимодействие между сервисами 
ins-product-aggregator, 
core-app и 
ins-comp-settlement 
осуществляется синхронно через REST API по расписанию. 
Как следствие, возможна неконсистентность данных в определённых сценариях и их невозможность завершения для пользователя.

# Список рисков:
- При увеличении нагрузки может возрастать время обработки запроса, что приведёт к каскадному замедлению или ошибкам вызова. 
Как следствие, следующие вызовы по расписанию должны будут обработать ещё больше данных, что ухудшит ситуацию.
- Подобные интеграционные алгоритмы, которые похоже что заменяют собой ETL-процесс, не масштабируются.
