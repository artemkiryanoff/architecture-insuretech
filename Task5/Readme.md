# Объяснение GraphQL схемы
Типы данных:
Client — содержит информацию о клиенте и связанные с ним данные
Document — представляет документ клиента
Relative — представляет родственника клиента

Запросы (Queries):
client — позволяет получить полную информацию о клиенте, включая связанные документы и родственников
clientDocuments — позволяет получить только документы клиента
clientRelatives — позволяет получить только родственников клиента

Преимущества GraphQL решения:
Гибкость запросов — клиент может запрашивать только необходимые поля, избегая избыточных данных
Меньше запросов — можно получить все связанные данные за один запрос
Динамичность — структура ответа полностью определяется запросом клиента
