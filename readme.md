# Task 1:
# Задание 1. Проектирование технологической архитектуры

Стратегия масштабирования и отказоустойчивость: горизонтальная, так как позволяет распределять нагрузку между новыми узлами

Конфигурация развёртывания приложения в Kubernetes: растянутый кластер, возможность гибкой настройки развертывания приложений

Балансировка нагрузки: GLSB для балансировки по геозонам и ALB для балансировки доступности и нагруженности подов

Подходящая Фейловер-стратегия:  Active - Active, для равномерного распределения нагрузки

Конфигурация базы данных: Patroni PostgreSQL для репликации БД, etcd для хранения конфигурации distributive. Без шардирования. 

Health Сheck: Loader Balancer периодически опрашивает pods и распределяет нагрузку между доступными pods
